# UK Road Casualty Statistics Visualisation (2020–2024)

## Project Overview
This project analyses UK road casualty data (2020–2024) from the Department for Transport using Python and Power BI to identify trends in collisions, casualties, and road safety risks.

## Dataset
UK Department for Transport Road Safety Open Data containing collision, vehicle, and casualty records.

https://www.gov.uk/government/statistical-datasets/road-safety-open-data

## Tools Used
- Python (Pandas, NumPy, Plotly, Matplotlib)
- Microsoft Power BI
- DAX

## Key Analysis
- Temporal trends in collisions
- Geographic collision hotspots
- Age and casualty distribution
- Road type and severity analysis
- Animated and interactive visualisations

## Key Insights
- Urban areas have the highest collision density
- Night-time and weekends show higher fatality risk
- Young drivers are most frequently involved in collisions
- Single carriageways show higher severity outcomes

## Conclusion
The analysis highlights clear spatial and temporal patterns in UK road casualties and demonstrates the effectiveness of interactive visual analytics for road safety insights.
